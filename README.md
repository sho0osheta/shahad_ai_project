# مشروع السوبر ماركت الذكي (Smart Supermarket)
### مشروع مادة البرمجة باستخدام لغة بايثون

## وصف المشروع:
برنامج يحاكي نظام السوبر ماركت الذكي، حيث يمكن للمستخدم إدارة المنتجات، حساب الفواتير، وتسهيل عملية التسوق برمجياً.

## التقنيات المستخدمة:
* لغة البرمجة: **Python**
* البيئة التطويرية: **Google Colab**

## إعداد وتطوير:
* تم تطوير هذا المشروع بواسطة مجموعة من طالبات تخصص الذكاء الاصطناع
